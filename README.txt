Giraffe Learning Words — initial browser port

Open index.html in a browser for local testing. For offline PWA installation, host the folder on an HTTPS website.
This is an initial working port, NOT a fully faithful 1:1 migration. Features such as audio, full SwiftUI screen flows, settings, and some training validation remain to be ported and verified.
Local storage is per browser/device. Export JSON regularly.
Do not remove the existing iOS app if it contains data.

Version 2: additional original iOS settings (input mode placeholder, training selection, auto-next preference, audio preference, transcription visibility). Existing localStorage key unchanged. Audio recording and voice input are not yet implemented.
